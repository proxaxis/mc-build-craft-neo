# Build Craft Neo — PLAYER'S GUIDE

このワールドは、工業と近代兵器の "科学技術" と、剣と魔法の "魔法技術" が共存する世界です. 
プレイヤーはワールド参加時にどちらかの陣営を選び、その陣営に沿った職業に就きます. 
このドキュメントは、ジョブ選びの参考になる世界の共通ルールをまとめたものです. 

各ジョブの詳しいマニュアルは `/docs/jobs/<JOB>.md` にあります.

* [戦士 - Warrior](jobs/Warrior.md)
* [暗殺者 - Assassin](jobs/Assassin.md)
* [守護者 - Guardian](jobs/Guardian.md)
* [魔道士 - Mage](jobs/Mage.md)
* [聖職者 - Healer](jobs/Healer.md)
* [弓使い - Archer](jobs/Archer.md)
* [科学使い - Scientist](jobs/Scientist.md)

## 1. 陣営を選ぶ

ワールドに初めて参加すると、チャットに陣営選択の案内が表示されます. 

```
/bcn join science   # 科学技術陣営に参加
/bcn join magic     # 魔法技術陣営に参加
```

- 陣営は一度きりの選択です.  参加済みのプレイヤーがもう一方に入り直すことはできません. 
- 両陣営は排他的で、対向陣営の専用アイテムは一切扱えません. 
- 不足する成果物はプレイヤー間取引で補い合うのがこの世界の基本です.
- 科学陣営は機械部品、精製資源を、魔法陣営は異世界のドロップや戦力を提供し合いましょう. 

### 陣営ごとの大きな違い

| | 科学技術陣営 | 魔法技術陣営 |
| :--- | :--- | :--- |
| 職業 | 科学使い固定 | 戦士 / 暗殺者 / 守護者 / 魔道士 / 聖職者 / 弓使い |
| 武器 | 銃火器 + ツール類のみ | 剣、メイス、魔法具など幅広く使用可（弓は弓使いのみ） |
| MP | 0（魔法は使えない） | 職業に応じて 100〜200 |
| 主な仕事 | 採掘、加工、発電、物流、火力支援 | ダンジョン攻略、対ボス戦、防衛、回復 |

## 2. 世界の 4 つの単位

この世界には 4 つのリソース単位があります. 

### MJ — Minecraft Joules（工業動力）

- 機械を動かすエネルギー単位. 発電機（エンジン）が燃料を燃やして MJ を生み出し、隣接する機械に直接供給されます. 
- クァーリーや粉砕機の稼働に必要です. 魔法陣営のプレイヤーが直接扱うことはありません. 

### MD — Minecraft Dollar（お金）

- この世界の通貨.
- 全プレイヤーに電子ウォレットがあり、残高は `/bcn md get <名前>` で確認できます. 
- ゲーム内では 6 種類のコインとしても流通します. 

| コイン | 価値（MD）|
| :--- | ---: |
| 銅貨 Copper Coin | 1 |
| 鉄貨 Iron Coin | 10 |
| 金貨 Gold Coin | 100 |
| エメラルド貨 Emerald Coin | 1,000 |
| ダイヤモンド貨 Diamond Coin | 10,000 |
| ネザライト貨 Netherite Coin | 100,000 |

* コインを持っているとウォレットに両替（預入）でき、逆に残高からコインを引き出す（引出）こともできます. 引き出しは高額コインから順に自動で両替されます.
* プレイヤー間の送金は `/bcn md pay <送金元> <送金先> <金額>` で行えます.
* お金は、物資の売買、職業リセット費用、土地の維持管理費などに使用します. 

### MP — Magic Point（魔力）

- 魔法陣営のスペル、アビリティを使うためのリソース. 科学陣営は MP を持ちません（上限 0）. 
- 上限は職業で変わります. 時間経過で自然回復します. 

| 職業 | MP上限 | 回復速度 |
| :--- | ---: | ---: |
| Mage | 200 | 3 MP/秒 |
| その他の魔法陣営職 | 100 | 1 MP/秒 |
| 科学陣営（Scientist） | 0 | — |

現在値は `/bcn mp get <名前>` で確認できます. 

### EFP — Environmental Foot Print（環境負荷指数）

- 重工業の稼働や兵器使用によって、世界全体に蓄積される汚染指数です.
- 現在値は `/bcn efp get` で確認できます. 

| 主な発生源 | 上昇量 |
| :--- | ---: |
| スターリングエンジンが燃料1個を消費 | +0.5 |
| クァーリーが1ブロック採掘 | +1.0 |
| 粉砕機が1回加工 | +0.5 |
| 原子炉の稼働（100 tick ごと） | +0.2 |
| 原子炉のメルトダウン | +500 |

EFP が閾値（初期値 1000）を超えると、"災害" が発生します. 災害が 1 回発生すると EFP は閾値の半分だけ減少します.

## 3. 世界構造と異世界への行き方

### オーバーワールド

生活、工業、開拓の拠点となる通常世界. EFP が高まると襲撃イベントが起きます. 

### 異世界ディメンション

サーバーには攻略用の異世界が存在します. 魔法陣営の武力や、科学陣営の銃火器による遠征が想定されています. 

| ディメンションID | モチーフMOD | 世界観 |
| :--- | :--- | :--- |
| `buildcraftneo:twilight` | The Twilight Forest - 黄昏の森| 常に黄昏の深い森が広がる進行型ディメンション |
| `buildcraftneo:skyreach` | The Aether - 天空 | 雲の上に浮かぶ浮島世界. 落下に注意！ |

* 行き先の確認には、`/bcn dim list` コマンドを使用します.
* 移動するには、`/bcn dim tp <プレイヤー> <ディメンションID>` コマンドです.

#### 各ディメンションの攻略イメージ

- 黄昏の森: ボスは進行順にロックされており、ナーガ → リッチ → ミノッシュルーム → ヒドラ → ファントムナイト → アーガスト → アルファイエティ → 雪の女王の順に討伐して先へ進みます. 
- 天空: 青銅、銀、金の 3 大ダンジョンがあり、フレームの外へ落ちるとオーバーワールドへ落下します. 
- 厄災: オーバーワールド、ネザー、エンドの巨大構造物に眠るエンドゲーム級ボス群. 最高難度の腕試しコンテンツです. 

## 4. 装備制限（できること、できないこと）

陣営と職業によって使える武器厳格に決まっています. 禁止アイテムを装備して使おうとすると失敗し、装着中のアイテムは定期的に自動で外されてインベントリへ戻されます. 

| アイテム種別 | 科学陣営 | 魔法陣営 | 無所属 |
| :--- | :--- | :--- | :--- |
| 剣、槍、メイス、トライデント等の近接武器 | ✕ | ○ | ○ |
| 弓、クロスボウ等の飛び道具 | ✕ | Archer のみ ○ | ○ |
| ツール類（斧、ピッケル、シャベル、クワ） | ○ | ○ | ○ |
| 銃火器（`service_pistol` 等） | ○ | ✕ | ✕ |
| 魔法具、スペル/アビリティアイテム | ✕ | ○ | ✕ |
| 工業マシン | ○ | △（直接操作は制限想定） | △ |

> [!NOTE]
> 手持ちアイテムが自分に使えるかは `/bcn check <名前>` で確認できます. 

## 5. 災害と防衛戦

EFP が閾値（初期値 1000）を超えると、世界のリスポーン地点周辺に武装した襲撃部隊が出現します. 

- 襲撃内容: 鉄剣持ちゾンビ×4、スケルトン×3、ピリジャー×2（計 9 体、リスポーンから半径 20 ブロックの円周上）
- 発生後は EFP が閾値の半分だけ減少し、10 分間のクールダウンが入ります. 
- 防衛は両陣営の協力が前提です. 科学陣営は銃撃、トラップで、魔法陣営は範囲攻撃、壁役、回復で拠点を守りましょう. 
- 撃退報酬として希少資材、高額 MD、特殊素材が得られる想定です. 

## 6. 生活ユーティリティ

オーバーワールド限定で、スニークしながら正しいツールでブロックを壊すと、繋がった同種ブロックを最大64個まで一括破壊します. 

| 対象 | ツール |
| :--- | :--- |
| 原木、木材（CutAll） | 斧 |
| 鉱石（MineAll） | ピッケル |
| 土、砂、砂利系（DigAll） | シャベル |

> [!NOTE]
> ツールの耐久値は壊した分だけ通常通り消費されます.

## 7. 工業マシン早見表（科学陣営向け）

Scientist が扱う機械の一覧です. 詳細は [scientist.md](jobs/scientist.md) を参照. 

| ブロックID | 役割 | 主なスペック |
| :--- | :--- | :--- |
| `stirling_engine` | 発電機 | 石炭/木炭/ブレイズロッドを燃焼、+4 MJ/t、燃料1本=1600tick |
| `nuclear_reactor` | 原子力発電 | ウラニウムインゴットで +100 MJ/t. 要、隣接水冷却. メルトダウンで大爆発+EFP+500 |
| `quarry` | 露天掘り | 5x5範囲を最大64深さまで自動採掘、50 MJ/ブロック |
| `macerator` | 粉砕機 | 鉱石→ダスト2個に倍加（100 MJ、40tick/回）. ダストは精錬でインゴット化 |
| `item_pipe` | 物流パイプ | 隣接コンテナから10tick毎に8個吸い出し、パイプ網経由で搬送 |
| `teleport_pipe` | ワイヤレス搬送 | 同一ディメンション、同一チャンネル(0-7)間でアイテム無線輸送 |
| `request_pipe` | オンデマンド取出 | パイプ網から指定アイテムを検索して取り寄せ |

## 8. プレイヤーが使えるコマンド

| コマンド | 内容 |
| :--- | :--- |
| `/bcn join science\|magic` | 陣営への参加（初回のみ） |
| `/bcn status <名前>` | 自分/他人の陣営、職業、MD、MPを表示 |
| `/bcn check <名前>` | 手に持っているアイテムが使用可か判定 |
| `/bcn md get <名前>` / `/bcn md pay <元> <先> <額>` | 残高確認 / 送金 |
| `/bcn mp get <名前>` | MP確認 |
| `/bcn efp get` | 世界の環境負荷を確認 |
| `/bcn dim list` / `/bcn dim tp <名> <dim>` | ディメンション一覧 / 移動 |
| `/bcn info` | MOD動作確認 |
