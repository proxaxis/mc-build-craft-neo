# Assassin — 暗殺者

> **陣営**: 魔法技術陣営 / **役割**: 機動アタッカー（斥候・奇襲）
> **源流MOD**: Wall-Jump! + Simply Swords（短剣系）

圧倒的な機動力で戦場を駆け巡り、敵の虚を突いて瞬時に仕留める高機動アタッカー。
体力は低い代わりに、誰よりも速く動き、誰にも捕まらないヒット＆アウェイのスペシャリストです。

## できること

- **近接武器を装備可能**（短剣・サイ・刀などの高速武器が本領）。
- **パッシブ**:
  - 移動速度 **+30%**（常時）
  - **ジャンプブーストI** を常時付与 — 壁蹴り・高所移動を活かした立体的な立ち回りが可能（Wall-Jump! 由来のパルクール設計）。
- **固有アビリティ「シャドウステップ」** (`ability_shadowstep`):
  - MP消費 15 / クールダウン 5秒
  - 効果: 視線方向へ **6ブロック瞬間移動** し、3秒間 **スピードII + 力I** を得る。敵の背後への滑り込み・緊急離脱の両方に使えます。
- **MP**: 上限 100、1 MP/秒 で自然回復。

## できないこと・制約

- **弓・クロスボウは装備不可**（Archer のみ使用可）。
- **銃火器・重装備での正面戦闘は不向き**: 防御面のボーナスがなく、被弾・囲まれると一気に危険。殴り合いは Warrior/Guardian の仕事です。

## おすすめ武器

| 武器系 | 特徴 |
| :--- | :--- |
| サイ / ダガー | 最速の手数。Simply Swords では背後からのバックスタブダメージ増加 |
| レイピア | 高速の突き。装甲無視系の攻撃 |
| 刀 | 機動力を活かした切り込みとコンボ |

短く速い武器で「当てて離れる」を繰り返すのが基本。移動速度+30%と相まって、敵の攻撃モーションの外を常に取り続けられます。

## 立ち回りガイド

- **背後を取れ**: シャドウステップで敵の真後ろへワープ → 短剣連撃が黄金パターン。正面からの斬り合いは避けましょう。
- **偵察・先回り**: 移動速度を活かしてダンジョンの先読み、宝箱回収、敵構成の報告役に適任です。
- **逃げスキルとしてのシャドウステップ**: 囲まれたら視線を安全方向へ向けて発動。6ブロックの瞬間移動はほぼすべての包囲を抜けられます。
- **災害防衛**: 壁の外を機動力で回り、射手（スケルトン・ピリジャー）を優先して各個撃破。タンクが抑えた敵の背後を取り続けましょう。
- **異世界遠征**: 黄昏の森の探索では高機動が真価を発揮。ただし浮島世界（skyreach）では勢い余っての落下死に最大限注意。

## お金の稼ぎ方

- 高機動を活かしたダンジョン先行クリア・レアドロップの早期確保。
- 危険地帯の偵察・輸送（テレポートパイプ網がない遠隔地間の手運び）。
- 災害防衛報酬。
