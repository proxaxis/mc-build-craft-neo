# Guardian — 守護者

> **陣営**: 魔法技術陣営 / **役割**: メインタンク（壁・ヘイト管理）
> **源流MOD**: Shield Expansion + 片手武器

大型盾と重装鎧をまとい、仲間への攻撃を一身に受け止める不沈の盾。
攻撃を引きつけ・耐え・仲間を守ることに特化した、パーティの要となるタンク職です。

## できること

- **近接武器を装備可能**: 片手剣・メイスなど盾と併用できる武器が基本（盾はオフハンド運用）。
- **パッシブ**:
  - **ノックバック完全無効**（ノックバック耐性 100%）— どんな攻撃を受けても位置を維持できます。
  - **ダメージ耐性I を常時付与**（被ダメージ -20%）。
  - Shield Expansion 由来の設計として、ジャストガード（パリィ）によるスタン反撃・オフハンドガードを想定した盾役ビルドです。
- **固有アビリティ「タウント」** (`ability_taunt`):
  - MP消費 15 / クールダウン 10秒
  - 効果: 半径14ブロックの敵モブの **攻撃対象を自分に強制変更** し、さらに5秒間 **耐性II（被ダメージ大幅軽減）**。味方への攻撃を一手に引き受けるヘイト確保スキル。
- **MP**: 上限 100、1 MP/秒 で自然回復。

## できないこと・制約

- **弓・クロスボウは装備不可**（Archer のみ）。
- **攻撃性能は控えめ**: パッシブに火力系ボーナスがなく、移動も重め。単独でのボス削りや高速戦闘には向きません。
- 敵を倒すのは味方の仕事 — あなたは「倒されないこと」と「敵を自分に向け続けること」に集中します。

## おすすめ装備

| 装備 | 特徴 |
| :--- | :--- |
| 片手剣 / メイス + 大型盾 | 基本形。盾で受けて隙に反撃 |
| 重装鎧一式 | 耐性Iと合わせて被ダメージを最小化 |
| ノックバック系武器 | 敵を味方から引き剥がす用途にも |

## 立ち回りガイド

- **先頭に立つ**: ダンジョンでも防衛戦でも、常にパーティの最前列。敵の視線を自分に集めてから味方に攻撃を任せます。
- **タウントのタイミング**: 味方（特に Mage/Healer）が狙われた瞬間に発動。耐性IIの5秒間はほぼ無敵に近いので、ピンチの切り返しにも使えます。
- **ノックバック無効を活かす**: 爆破系・飛ばし系の攻撃で味方陣形が崩れる場面でも、あなただけは動かない壁になれます。崖際・ラバ際でも安心して前線を張れます。
- **災害防衛**: 拠点の入口に立ち、襲撃者を自分に集めて入口を封鎖。背後の Archer/Mage/銃持ちの Scientist が撃ち抜きます。
- **異世界遠征**: 黄昏の森のボス戦・厄災級ボスとの対峙では、タンクの有無が攻略可否を分けます。Healer と常にセットで動きましょう。

## お金の稼ぎ方

- 高難度ダンジョン・ボス戦へのタンク役としての同行（攻略不可欠な職のためパーティ需要が高い）。
- 災害防衛の最前衛としての報酬。
- 危険地帯での護衛依頼（科学陣営の採掘隊護衛など）。
