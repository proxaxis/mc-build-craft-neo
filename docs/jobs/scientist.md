# Scientist — 科学使い

> **陣営**: 科学技術陣営（この陣営を選ぶと Scientist 固定）/ **役割**: 工業・自動化・近代兵器
> **源流MOD**: BuildCraft + IndustrialCraft 2 + Logistics/Additional Pipes + Vic's Point Blank (+ GvC/HMG)

剣も弓も魔法も持たず、機械・パイプ網・銃火器で世界を切り拓くエンジニア。
資源の大量採掘・加工・発電・物流のすべてを担い、サーバーの工業基盤そのものを支える生産職です。

## できること

- **銃火器を使用可能**（科学陣営専用）:
  - **制式拳銃** (`service_pistol`): 右クリックで弾丸発射。ダメージ8・約0.4秒間隔で連射可能。魔法を使えない科学陣営の主力兵装です。源流の Vic's Point Blank ではアサルトライフル・スナイパー等へのアタッチメント改造を想定。
- **ツール類を装備可能**: 斧・ピッケル・シャベル・クワは自由に使用可。スニーク+ツールで CutAll/MineAll/DigAll の一括採掘も使えます。
- **工業マシンを扱う**: 発電機・クァーリー・粉砕機・パイプ網など、工業設備の設置・運用・保守はあなたの領域です（詳細は下表）。

## できないこと・制約（重要）

- **ファンタジー武器は一切使用不可**: 剣・槍・メイス・トライデント、弓・クロスボウは ItemLocks 式の制限で完全に封印。装備しても使えず、装着し続けると自動で外されます。
- **魔法は一切使えない**: スペル・アビリティアイテムを使えず、**MP上限は0**。魔法陣営の成果物（回復・支援魔法）は取引で補いましょう。
- 職業は Scientist 固定で、他職へは就けません。

## 主な工業設備

| ブロック | 役割 | 燃料/消費 | 備考 |
| :--- | :--- | :--- | :--- |
| `stirling_engine` | 基本発電機 | 石炭/木炭/ブレイズロッド1個=1600tick、+4 MJ/t | 隣接した機械に直接送電。燃料1個でEFP+0.5 |
| `nuclear_reactor` | 高出力発電 | ウラニウムインゴット1個=1600tick、+100 MJ/t | **隣接に水を置き冷却必須**。熱100でメルトダウン（大爆発+EFP+500） |
| `quarry` | 自動露天掘り | 50 MJ/ブロック・10tick毎 | 設置点直下5x5を深さ64まで全自動採掘。掘れば掘るほどEFP+1/個 |
| `macerator` | 鉱石粉砕 | 100 MJ・40tick/回 | 鉱石1個→ダスト2個に**倍加**。ダストはかまど精錬でインゴット化（鉄/金/銅レシピあり）。丸石→砂利→砂にも変換可 |
| `item_pipe` | アイテム輸送 | 10tick毎に8個吸出 | 隣接チェスト等から取り出し、パイプ網（最大32ホップ）経由で到達可能なコンテナへ搬送 |
| `teleport_pipe` | 無線輸送 | 10tick毎に8個 | 同一ディメンション・同一チャンネル(右クリックで0-7巡回)の別テレポートパイプの隣接コンテナへ即時輸送 |
| `request_pipe` | オンデマンド取出 | 20tick毎に検索 | 指定アイテムをパイプ網（最大64ホップ）内から取り寄せて隣接コンテナへ搬入（Logistics Pipes相当） |

- 機械の状況はブロック右クリック、または `/bcn machine info <座標>` で確認できます。

## 環境負荷（EFP）との付き合い方

科学陣営の稼働は世界のEFPを押し上げ、**1000を超えると襲撃イベントが発生**します。

- クァーリーは1ブロック掘るごとに+1、エンジン燃料は1個ごとに+0.5、原子炉メルトダウンは一気に+500。
- EFPは世界共有資源 — あなたの工業拡張がサーバー全員の災害リスクになります。稼働の計画性と防衛準備はセットで考えましょう。
- 逆に災害が起きれば防衛戦の主力にもなれます。銃で襲撃者を撃ち抜き、撃退報酬を得ましょう。

## 立ち回りガイド

- **電源から始める**: まずスターリングエンジン+燃料確保 → クァーリー/粉砕機の順で基盤を作ります。発電機は消費機械に隣接させる必要があります。
- **倍加で儲ける**: 粉砕機で鉱石を2倍にして精錬すれば、掘った鉱石の価値が倍増。これが科学陣営の基本の儲け筋です。
- **物流網を引く**: item_pipe で採掘拠点→粉砕→精錬→倉庫を自動化。遠くの拠点間は teleport_pipe の同一チャンネルで無線輸送。
- **原子炉は冷却を怠らない**: 隣接6面のいずれかに水が無いと冷却できず、熱100でメルトダウン=大爆発+EFP+500。設置場所と水の確保を最優先で。
- **災害防衛では銃撃手**: 魔法陣営が入口を守る間、あなたは拳銃で壁の上から撃ち続けます。

## お金の稼ぎ方

- **加工資源の販売**: 倍加ダスト→精錬インゴット、ウラニウム、精製資源を魔法陣営・市場へ売却。
- **クァーリーによる大量素材供給**: 建材・鉱石を量産して卸売。
- **物流・インフラの請負**: テレポートパイプ網や自動化ラインの設置代行。
- 災害撃退報酬・土地の維持管理に備えた運転資金の確保。
