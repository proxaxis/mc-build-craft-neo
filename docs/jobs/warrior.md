# Warrior — 戦士

> **陣営**: 魔法技術陣営 / **役割**: 近接アタッカー（前衛火力）
> **源流MOD**: Simply Swords + Better Combat

前線に立ち、重い両手武器の一撃と範囲薙ぎ払いで敵陣を粉砕する物理アタッカー。
チームの主力ダメージソースとして、ダンジョン攻略・災害防衛のどの場面でも安定した活躍が期待できる、最もオーソドックスな前衛職です。

## できること

- **あらゆる近接武器を装備可能**: 剣全般（クレイモア・大斧・刀・レイピア等）、メイス、槍、トライデントまで、魔法陣営の近接武器をすべて扱えます。
- **パッシブ**: 攻撃力 **+20%**（常時）。
- **固有アビリティ「ウォークライ」** (`ability_warcry`):
  - MP消費 20 / クールダウン 10秒
  - 効果: 半径10ブロックの味方全員に **力II（攻撃力上昇）10秒**、半径10ブロックの敵モブに **衰弱I 10秒**。集団戦の開始合図に使うバフ＆デバフスキル。
- **MP**: 上限 100、1 MP/秒 で自然回復。

## できないこと・制約

- **弓・クロスボウは装備不可**（魔法陣営で飛び道具を使えるのは Archer のみ）。遠距離は味方の Archer/Mage か、科学陣営に任せましょう。
- **銃火器は使用不可**（科学陣営専用）。
- 魔法陣営の汎用スペル（`apprentice_wand` 等）は使えますが、他職専用のアビリティアイテムは発動しません。

## おすすめ武器（Simply Swords 系）

| 武器系 | 特徴 |
| :--- | :--- |
| クレイモア / グレートハンマー | 低速・高火力。単体ボスや重装甲に |
| グレートアックス / ハルバード | 出血効果、範囲が広く集団戦向き |
| ツインブレード / ワーグレイブ | 高速連撃で手数勝負 |
| 刀 / ロングソード | バランス型。扱いやすい本命 |

Better Combat により武器ごとに固有の攻撃モーション・リーチ・ヒット判定があります。自分の間合いに合う武器を選びましょう。

## 立ち回りガイド

- **開幕にウォークライ**: ボス戦・襲撃イベント開始時にまずバフを撒き、パーティ全体の火力を底上げするのが戦士の第一の仕事です。
- **Guardian と組む**: タンクがヘイトを取っている間に側面・背後から高火力を叩き込むのが理想形。
- **災害防衛**: 襲来するゾンビ・ピリジャーの波を近接で掃討する中核。壁の内側で迎え撃ちましょう。
- **異世界遠征**: 黄昏の森（`buildcraftneo:twilight`）や浮島世界（`buildcraftneo:skyreach`）では前衛の筆頭。迷子・落下に注意しつつ道を切り開きます。

## お金の稼ぎ方

- ダンジョン・異世界のドロップ素材を、加工手段を持つ科学陣営プレイヤーへ販売。
- 災害イベントの防衛報酬（MD・希少素材）。
- 採取系は MineAll/CutAll（スニーク+ツール）で素早く集めて売却するのも手。
