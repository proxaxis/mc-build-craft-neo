# Scientist — 科学使い

> **陣営**: 科学技術陣営（この陣営を選ぶと Scientist 固定）/ **役割**: 工業・自動化・近代兵器
> **源流MOD**: BuildCraft + IndustrialCraft 2 + Logistics Pipes / Additional Pipes + Vic's Point Blank（+ GvC/HMG）

剣も弓も魔法も持たず、機械・パイプ網・銃火器で世界を切り拓くエンジニア。
資源の大量採掘・加工・発電・物流のすべてを担い、サーバーの工業基盤そのものを支える生産職です。

※ Scientist の源流 MOD 群は `docs/mods/` にリファレンスが無いため、本ファイルは原作 MOD の一般的な仕様に基づく。

## できること

- **銃火器を使用可能**（科学陣営専用）: Point Blank 系の近代銃器。魔法を使えない科学陣営の主力兵装。
- **ツール類を装備可能**: 斧・ピッケル・シャベル・クワは自由に使用可。スニーク+ツールで一括採掘（Vein/CutAll 系）も使える。
- **工業マシンを扱う**: 発電機・採掘機・加工機・パイプ網など、工業設備の設置・運用・保守はあなたの領域。

## できないこと・制約（重要）

- **ファンタジー武器は一切使用不可**: 剣・槍・メイス・トライデント、弓・クロスボウは完全に封印。
- **魔法は一切使えない**: スペル・スペルブック・ルーン体系を使えない。魔法陣営の成果物（回復・支援）は取引で補う。
- 職業は Scientist 固定で、他職へは就けない。

## 源流システム① — BuildCraft（採掘・建築・輸送）

BuildCraft は「掘る・運ぶ・建てる」を機械化する工業 MOD の祖。エネルギー単位は **MJ**。

### 発電（エンジン）

| 機械 | 役割 |
| :--- | :--- |
| Redstone Engine | 最弱・常時微弱出力。ポンプ等の低速駆動用 |
| Stirling Engine | 石炭・木炭・溶岩バケツ等を燃やす基本発電機 |
| Combustion Engine | 燃料（Fuel/石油/バイオ燃料）を燃やす高出力機。冷却に水が必要 |
| Creative Engine | 無限出力（クリエイティブ/管理用） |

- エンジンは隣接した機械・動力管へ MJ を送る。燃料が切れると停止。
- 内燃機関は**冷却必須** — 水が無いと過熱して爆発する。

### 採掘・建築機械

| 機械 | 役割 |
| :--- | :--- |
| Quarry | 設置した範囲（ランドマークで指定）を岩盤まで自動露天掘り。最大の資源生産機 |
| Mining Well | 直下を縦に掘り続ける小型自動採掘機 |
| Pump | 液体（水・溶岩・石油）を汲み上げて管へ送る |
| Refinery | 原油を燃料へ精製 |
| Assembly Table + Laser | 高度素材（チップ・ゲート部品）をレーザー加工で製作 |
| Filler | 指定パターンでブロックを自動敷設/撤去 |
| Builder / Architect Table | 設計図通りに構造物を自動建築 |

### 輸送管（Item Pipe / Fluid Pipe / Kinesis Pipe）

| 管 | 役割 |
| :--- | :--- |
| Wooden Pipe | コンテナからアイテムを**吸出**（動力必要） |
| Cobblestone / Stone / Quartz Pipe | 基本輸送。材質違いは接続されない（混線防止） |
| Iron Pipe | 一方向のみ通す（合流・逆流防止） |
| Golden Pipe | 通過アイテムを**加速** |
| Diamond Pipe | **色分け仕分け** — アイテムを 6 面へ分配 |
| Obsidian Pipe | 床に落ちたアイテムを**吸引回収** |
| Emerald Pipe | フィルタ付き吸出（高度な抽出制御） |
| Void Pipe | 通過アイテムを**消去**（オーバーフロー対策） |
| Lapis / Daizuli / Emzuli | 色付き経路制御・高度なルーティング管 |
| Fluid Pipe | 液体輸送（木製吸出 + 各材質） |
| Kinesis Pipe | MJ 動力を管で送電（木製出力 + 各材質） |
| Tank | 液体の貯蔵ブロック |

### ロボット・ドッキング（BuildCraft 7 系）

- ドッキングステーションにロボットを載せ、採掘/伐採/運搬/整地など作業型ロボットを運用できる。

## 源流システム② — IndustrialCraft 2（電気・加工・原子力）

IC2 は電気エネルギー **EU** を中心とする重厚な工業 MOD。

### 発電・蓄電

| 機械 | 役割 |
| :--- | :--- |
| Generator | 燃料を燃やす基本発電機 |
| Geothermal Generator | 溶岩を EU に変換 |
| Solar / Wind / Water Mill | 自然エネルギー発電（設置環境依存） |
| Nuclear Reactor | ウラン燃料棒で莫大な EU。**冷却管理が命** — 熱が溜まるとメルトダウン大爆発 |
| BatBox / MFE / MFSU | EU 蓄電池（段階的容量） |

### 加工機械（EU 消費）

| 機械 | 役割 |
| :--- | :--- |
| Macerator | 鉱石1個 → **ダスト2個**（鉱石倍加）。ダストは精錬でインゴット化 |
| Extractor | ゴム・バイオ燃料等の抽出 |
| Compressor | 素材の圧縮（炭素繊維・高級素材） |
| Electric Furnace | 電気炉（高速精錬） |
| Metal Former | 金属の成形・延圧・押出 |
| Recycler / Mass Fabricator | 廃材を UU-Matter に再生し任意素材を生成 |
| Uranium 加工系 | 燃料棒・MOX の製造ライン |

### 装備

- **Nano Suit / Quantum Suit**: EU で充電する高級装甲。
- **Mining Laser**: EU 消費の掘削・攻撃ビーム。
- **各種ツール**: 電動ドリル・チェーンソー等。

| Chassis Pipe + モジュール | 管に拡張スロットを持たせ、機能を積む |
| ├ Extractor Module | 指定条件でコンテナから抽出 |

## 源流システム⑤ — Vic's Point Blank（銃火器）

近代銃器を実装する FPS 系 MOD。

- **銃カテゴリ**: ハンドガン / SMG / アサルトライフル / DMR / スナイパー / ショットガン / LMG。
- **アタッチメント**: サイト・スコープ・サプレッサー・マズルブレーキ・フォアグリップ・ストック・拡張マガジン等で銃を改造。
- **弾薬・リロード**: マガジン制（残弾管理）。ADS（エイムダウンサイト）で精密射撃。
- **射撃演出**: プロシージャルな反動・リロード・検査アニメーション（クライアント描画が本質）。

## 源流システム⑥ — GvC / HMG（戦闘コンテンツ）

- **ゲリラ兵・傭兵モブ**: 銃を持った敵性 NPC が襲撃してくる戦闘コンテンツ。
- **車両（HMG）**: 運転可能な車両（検証には実クライアント必須）。

## 環境負荷との付き合い方

科学陣営の稼働は世界に負荷を与え、襲撃イベントを引き起こす設計になっている。

- 大量採掘・発電・原子力ほど負荷が大きい — あなたの工業拡張がサーバー全員の災害リスクになる。
- 稼働の計画性と防衛準備はセットで考える。
- 逆に災害が起きれば防衛戦の主力にもなれる。銃で襲撃者を撃ち抜き、撃退報酬を得よう。

## 立ち回りガイド

- **電源から始める**: まず発電手段（Stirling/Generator）+ 燃料確保 → 採掘機・加工機の順で基盤を作る。発電機は消費機械に隣接 or 動力管で送電する必要がある。
- **倍加で儲ける**: IC2 の Macerator で鉱石を2倍にして精錬すれば、掘った鉱石の価値が倍増。これが科学陣営の基本の儲け筋。
- **物流網を引く**: 管で採掘拠点→加工→精錬→倉庫を自動化。遠くの拠点間は Teleport Pipe の同一チャネルで無線輸送。
- **原子炉は冷却を怠らない**: IC2 の Nuclear Reactor は冷却を怠るとメルトダウン（大爆発）。設置場所と冷却の確保を最優先で。
- **Logistics Pipes で供給自動化**: 拠点が大きくなったら Request/Supplier/Crafting 管で「在庫が減ったら自動で作って補充する」網を構築。
- **災害防衛では銃撃手**: 魔法陣営が入口を守る間、あなたは銃で壁の上から撃ち続ける。

## お金の稼ぎ方

- **加工資源の販売**: 倍加ダスト→精錬インゴット、ウラニウム、精製資源を魔法陣営・市場へ売却。
- **クァーリーによる大量素材供給**: 建材・鉱石を量産して卸売。
- **物流・インフラの請負**: テレポートパイプ網や自動化ラインの設置代行。
- **銃・アタッチメント・弾薬の製造販売**。
- 災害撃退報酬・土地の維持管理に備えた運転資金の確保。
