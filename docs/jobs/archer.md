# Archer — 弓使い

> **陣営**: 魔法技術陣営 / **役割**: 遠距離狙撃（単体撃破・制圧射撃）
> **源流MOD**: Archers (RPG Series)

魔法陣営で唯一「弓・クロスボウ」の所持と射撃が許されたスナイパー。
前衛の届かない距離から敵を削り、要所の敵を一撃で射抜く遠距離火力職です。

## できること

- **弓・クロスボウを装備可能**: 魔法陣営で飛び道具を使えるのは Archer だけ。遠距離制圧はあなたの独占領域です。
- **近接武器も装備可能**（護身用。本領は弓）。
- **固有アビリティ「レインオブアローズ」** (`ability_rain_of_arrows`):
  - MP消費 30 / クールダウン 15秒
  - 効果: 視線の先約10ブロック地点の上空から **12本の矢を降らせる**（1本あたりダメージ6）。範囲制圧と足止めの面攻撃。
- **固有アビリティ「ピアスショット」** (`ability_pierce_shot`):
  - MP消費 15 / クールダウン 5秒
  - 効果: 視線方向へ **ダメージ25の高速矢** を発射（ブレなし・高初速）。ボスや高耐久の敵を確実に削る単発狙撃。
- **MP**: 上限 100、1 MP/秒 で自然回復。

## できないこと・制約

- **接敵が弱点**: 近接特化のパッシブがなく、取り付かれると不利。間合いの管理が生命線です。
- 魔法陣営の他職専用アビリティは使えません（弓系スキルのみがあなたの武器）。

## 立ち回りガイド

- **最長射程を常に維持**: 敵の攻撃が届かない距離からピアスショットで削るのが基本。高所・障害物の上など、射線が通りにくい位置を確保しましょう。
- **優先ターゲット**: スケルトン等の射撃敵・呪術系・集団の後衛。前衛（Warrior/Guardian）に任せる敵と、自分で潰すべき敵を瞬時に選別します。
- **レインオブアローズは「固まった敵」に**: Guardian のタウントで集まった敵・入口に群がる襲撃者の頭上へ撃つのが最も効果的。
- **災害防衛**: 城壁・見張りから襲撃者を遠距離で撃ち抜く最重要火力。ピリジャー（射撃敵）はあなたが最優先で処理しましょう。
- **異世界遠征**: 黄昏の森の大型ボス（ナーガ・ヒドラ等）は間合いを取って削りやすい相手。浮島世界では遠距離から安全に浮島間の敵を処理できます。
