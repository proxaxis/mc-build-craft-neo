# 暗殺者 - Assassin

> 魔法技術陣営 / 高機動アタッカー

圧倒的な機動力で戦場を駆け巡り、敵の虚を突いて瞬時に仕留める高機動アタッカー.

## できること

- 近接武器を装備可能. 
- 壁掴み、壁蹴り、二段ジャンプ、スプリント、エリトラ加速、ステップアシスト. 

## できないこと、制約

- 弓、クロスボウは装備不可. 
- 防御面のボーナスを持たず、被弾、包囲は致命的. 殴り合いは Warrior/Guardian の仕事. 
- 高速機動には飢餓システムがある. 満腹度が尽きると壁技も二段ジャンプも出なくなる. 

## 全技 1 - 移動技

| 操作 | 結果 |
| :--- | :--- |
| 壁へ向かってジャンプ中に LSHIFT を押す | 壁掴み（Wall Cling） - 壁に貼り付く |
| 掴み中に LSHIFT を離しながら移動キー入力 | 壁蹴り（Wall Jump） - 壁から跳躍 |
| 空中でジャンプキー | ダブルジャンプ（設定/エンチャントで有効化） |
| スプリント | スピードブーストで加速 |
| エリトラ滑空 + スプリントキー+前入力 | エリトラ加速（スニークで減速） |
| 段差へ向かって歩く/跳ぶ | ステップアシストで自動乗り越え（フェンス越え含む） |

### Wall Cling（壁掴み）

- 空中で壁に接触した状態で専用キーを押す（4 tick 以内の押下のみ有効 = タップ判定）. 
- 発動条件: 非地上、非飛行、非液体、手が空いている、満腹度1以上、上昇中でない（Δy ≤ 0.1）. 高速落下中（Δy < -0.8）は設定により不可. 
- 掴み中は水平位置をロック、上昇は 0 にキャンセル. 奇襲の構え: 敵の頭上や壁際で待ち伏せできる. 
- 壁滑り: 掴み開始から 15 tick 後に -0.1/tick でゆっくり滑り落ちる. 
- 落下ダメージを滑り速度に応じて軽減. 

### Wall Jump（壁蹴り）

- 掴み中にキーを離し、移動キー入力があれば壁から跳躍. 上方向速度 0.55 + 視線反対方向への押し出し約 0.45 倍. Jump Boost で +0.125/Lv. 
- キーを離すだけでは跳ばず、移動キーが必須（その場落下も選択可）. 
- 再掴み制限: 同一面への連続掴みは禁止（別の壁 or 1ブロック上昇が必要）. `maxWallJumps` で滞空あたりの回数制限可能. 
- 壁蹴りごとに飢餓疲労 0.8. 

### Double Jump（二段ジャンプ）

- 空中でジャンプキーで追加ジャンプ. 基本 1 回 + ブーツの Double Jump エンチャント Lv 分（複数段可）. 
- 発動条件: 非地上、非液体、非掴み中、非騎乗、満腹度あり、下降速度が緩やか（Δy < 0.333）. 
- 発動時に落下距離リセット - 高所からの離脱にも使える. 

### Speed Boost（スピードブースト）

- スプリント中: `sprintSpeedBoost` + ブーツの Speed Boost エンチャント ×0.25 で視線方向へ加速. 空中では効果 1/3.125. 
- エリトラ滑空中: スプリントキー+前入力で `elytraSpeedBoost` + チェストのエンチャント ×0.5 で加速推進. スニークで 5% 減速. 

### Step Assist（ステップアシスト）

- 空中でも段差を自動乗り越え. スプリント中はフェンス等をまたげる - 追跡、逃走どちらにも効く. 

### エンチャント

| エンチャント | 部位 | 効果 |
| :--- | :--- | :--- |
| Wall Jump | ブーツ | 壁掴み/壁蹴りを解禁 |
| Double Jump | ブーツ | Lv ごとに空中ジャンプ回数 +1 |
| Speed Boost | ブーツ/チェスト | ブーツ=スプリント加速、チェスト=エリトラ加速に加算 |

## 立ち回りガイド

- 立体機動で背後を取る: 壁掴みで頭上に張り付き → 壁蹴りで敵の背後へ飛び込む → Sai/Dagger のバックスタブ（+20–40%）が黄金パターン. 
- 逃げは二段ジャンプ+壁蹴り: 囲まれたら壁へ. 二段ジャンプで高さを稼ぎ、壁蹴りで建物上へ離脱. 落下距離リセットで着地ダメージも消せる. 
- 満腹度を切らすな: 壁技も二段ジャンプも飢餓で止まる. 暗殺者にとって食料は弾薬. 
- 偵察、先回り: 機動力を活かしてダンジョンの先読み、宝箱回収、敵構成の報告役に適任. 
- 災害防衛: 壁の外を機動力で回り、射手（スケルトン、ピリジャー）を優先して各個撃破. 
- 異世界遠征: 黄昏の森では高機動が真価を発揮. ただし浮島世界（skyreach）では勢い余っての落下死に最大限注意 - 二段ジャンプの落下リセットが保険.
