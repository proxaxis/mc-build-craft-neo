# 守護者 - Guardian

> 魔法技術陣営 / メインタンク

大型盾と重装鎧をまとい、仲間への攻撃を一身に受け止める不沈の盾. スタミナ管理とジャストガード（パリィ）の技術介入型防御. 受けるだけでなく反撃もできる. 

## できること

- 片手武器 + 盾の運用: 片手剣、メイス、レイピアなどオフハンドに盾を持てる武器が基本. 
- Shield Expansion の全盾ティア: 木、金、鉄、ダイヤ、ネザライト盾 + バニラ盾. ティアでパリィ反撃、スタミナ、爆発耐性が変わる. 
- パリィ（ジャストガード）: 被弾直前に盾を上げるとノーダメージ+反撃. 飛び道具は 180° 反射. 

## できないこと、制約

- 弓、クロスボウは装備不可（Archer のみ）. 
- 両手武器は盾と併用不可: `two_handed` 武器はオフハンドを封じるため、クレイモア等を持つと盾が出せない. 
- 攻撃モーション中はガード不可: 攻撃の隙に被弾しやすい - 攻めすぎは禁物. 
- 攻撃性能は控えめ: 敵を倒すのは味方の仕事. あなたは "倒されないこと" と "敵を自分に向け続けること" に集中する. 

## 全技 1 - 盾の仕組み（Shield Expansion）

### ガード（基本動作）

- 盾を持って右クリック: ガード状態へ. 発動時にパリィ窓が `parryTicks` だけ開く. 
- ガード成立中は正面からの近接、飛び道具を無効化（視線方向 ±90° の射線判定. 貫通矢（Piercing）は貫く）. 
- ガード中は移動速度に `4.0 × speedFactor` の補正（バニラのガード鈍足より速く動ける）. 
- 攻撃モーション中（attackAnim > 0）はガード不可、即解除 - 攻撃と防御の切替テンポが盾使いの技術. 

### Off-Guard Cooldown（スタミナ + クールダウン）

盾は貼り続けられるものではない:

- ガードで受けた通常ヒット: ダメージ ≤5 でスタミナ -2、>5 で -3、飛び道具は -1. 
- スタミナ消費が盾の `stamina` に達すると Off-Guard: 盾が `cooldownTicks` 使用不能になり強制解除. 
- 自分から盾を下ろしても同じクールダウンが付く（貼りっぱなし、出し入れ回避の防止）. 
- `lenientStamina` 設定でスタミナ量 2 倍の緩和モードあり. 

### Parry（パリィ / ジャストガード）

- ガード開始から `parryTicks`（3〜6 tick = 0.15〜0.3 秒）以内に攻撃を受けると成立. 
- 近接攻撃: 攻撃者をノックバック（2段）+ `parryDamage×被ダメ+flatDamage` の反撃（Parry-Bash）. 
- 飛び道具: 弾を速度そのままに 180° 反射（スケルトンの矢を撃ち返せる）. 
- パリィ成功時は耐久消費1のみ、スタミナ消費なし → 連続パリィが決まれば盾は削れない. 
- 失敗（窓外）: 耐久を被ダメ分消費しスタミナ消費 → スタミナ切れで Off-Guard. 

### 爆発（特殊処理）

- 爆発は `blastResistance` を引いた残りで判定（griefer 盾は 100% 軽減=完全無効）. 
- パリィ窓中の爆発: 威力 ≥15 でクールダウン+強制解除、≥10 で半分の CD. 
- 窓外の爆発: 威力 >5 で即 CD（高威力ほど延長）. 
- `ADVANCED_EXPLOSIONS` 有効時は軽減しきれなかった分が partial blast ダメージとして素通りする.

## 立ち回りガイド

- 先頭に立つ: ダンジョンでも防衛戦でも、常にパーティの最前列. 敵の視線を自分に集めてから味方に攻撃を任せる. 
- パリィを狙え: バニラ盾〜鉄盾の 5t 窓は比較的広い. 敵の振りを読んで "被弾直前に盾を上げる" 練習が盾使いの基本. 決まればノーダメ+反撃+ノックバック. 
- スタミナを見る: 雑魚の連打でスタミナが削れると Off-Guard（盾が開く）. 盾を下ろすと CD が付くので、切りどきは "安全な距離で下ろす" か "張り続けて覚悟を決める" かの二択. 
- 盾を選べ: 序盤は木/金（窓が広く練習向き）、中盤は鉄（バランス）、慣れたらネザライト（3t 窓の上級者盾）か paragon（最強反撃）. 
- 災害防衛: 拠点の入口に立ち、襲撃者を正面で受ける. 背後の Archer/Mage/銃持ちの Scientist が撃ち抜く. 
- 異世界遠征: 黄昏の森のボス戦、厄災級ボスとの対峙では、タンクの有無が攻略可否を分ける. Healer と常にセットで動こう.
