# Neo Builder MOD for Minecraft Fabric Servers

ようこそ! この MOD は、BuildCraft、LogisticsPipes、IC2 などの往年の名作工業 MOD、Better Dungeons のような本格アクション MOD、経済システムをシームレスに体験できる複合 MOD です.

## 1. はじめに

本 MOD は Minecraft Java Edition (Fabric Loader) 向けに最適化されています. ゲームの快適なプレイには専用のリソースパックの有効化が必要ですので、サーバ参加時には確認をお願いします. また、このサーバに入ったら、"科学技術" を使うか、"魔法技術" を使うか選択します. これは排他的であり、他方の技術のアイテムを所持することはできません. 取引で解決しましょう!

* 科学技術陣営: 剣、弓、ボウガン、槍は使用できません. オノ、ピッケル、クワ、シャベルなどのツール類のみ使用可能です. 職業は `Scientist` に固定されます.
* 魔法技術陣営: 弓とボウガンを除くすべての武器が使用可能です. 弓とボウガンを使えるのは職業 `Archer` のみです. なお、職業 `Scientist` は選択できません.

## 2. 基本概念

### 2.1. 単位

#### 2.1.1. `MJ` - `Minecraft Joules`

* 基本となるエネルギー単位です. 
* 工業ではエンジンや発電機で生成され、電線やキネシスパイプを通じてマシンに供給されます.
* 工業では粉砕機、採掘機、ポンプなどの稼働に必須です.
* 魔術の出力を表すこともあります.

#### 2.1.2. `MDL` - `Minecraft Dollar`

* 基本となる経済単位です.
* プレイヤー間取引、ショップでの売買、土地の開放や維持などに使用されます. 

#### 2.1.3. `MP` - `Magic Point`

* 基本となる魔法使用単位です.
* 魔法の使用時に使用されます.

#### 2.1.4. `EFP` - `Minecraft Environmental Foot Print`

* プレイヤーの活動によって環境に与える影響を表す環境負荷指数です.
* 環境負荷をかけるプレイヤーは相応の対価を払わなければいけません!

### 2.2. 世界

#### 2.2.1. オーバーワールド

基本となる世界です. この世界では特殊なモブは沸きませんが、"災害" があることを忘れてはいけません. この世界では技術力とお金がものを言います.

#### 2.2.2. アドベンチャーワールド

特殊世界です. この世界では、ダンジョン、強力な敵、特殊なモブなどが沸きます. この世界で生き残るためには戦わなければなりません. 強くなりましょう. 勝てなければオーバーワールドに戻っても意味がありません.

## 3. 工業システム

科学技術陣営のプレイヤーは工業力を駆使してサバイバルを生き抜きましょう.

### 3.1. 動力とエンジン

* Redstone Engine: レッドストーン信号のみで動く低出力エンジン. パイプからのアイテム抽出に最適です.
* Stirling Engine: 石炭や木炭を燃料とする中型動力. 序盤の粉砕機やポンプの稼働に使用します.
* Combustion Engine: 冷却水と精製油などの燃料を消費して高出力を生み出す大型エンジンです.
* Nuclear Engine: 最高出力を誇る原子力エンジンです. コストパフォーマンスに優れますが、取り扱いには注意が必要です.

### 3.2 パイプと配送

* Transport Pipes: アイテムを搬送します. 木、石、鉄、金、ダイヤ、黒曜石など、材質ごとに分岐、加速、吸引の特性があります. 
* Teleport Pipes: 離れた拠点間やディメンションを越えてアイテム、液体、エネルギーを瞬時に無線転送します.
* Logistics Pipes: リクエストパイプやプロバイダーパイプを接続することで、チェストの中身を検索して手元へ自動納品したり、中間素材から完成品までのオンデマンド自動クラフトを実現します.

### 3.3. 採掘と整地と加工

* Quarry: 指定エリアを岩盤まで全自動採掘します. 動作には十分なエネルギーと広い土地が必要です.
* Filler: 整地、穴埋め、指定ブロックの置換を一瞬で行う建築補助マシンです.
* Macerator: 鉱石を粉砕して粉に変換します. 釜土で焼くことで鉱石を効率的に精錬することができます.

## 4. アドベンチャーシステム

魔法技術陣営のプレイヤーは魔法力を駆使してサバイバルを生き抜きましょう. 自分のプレイスタイルに合わせた職業を選択し、スキルツリーを解放できます.

### 4.1. 職業

* Warrior - 戦士: 高い近接火力を持ちます.
* Assassin - 暗殺者: 高い移動速度を持ちます.
* Guardian - 守護者: 高い耐久性能を持ちます.
* Healer - 癒す者: 高い治癒能力を持ちます. 他者を癒すこともできます.
* Mage - 魔道士: 呪文書を用いた魔法攻撃能力を持ちます.
* Archer - 弓使い: 本クラスを持つ者だけが弓やボウガンを使用できます.
* Scientist - 科学使い: 科学技術陣営専用の固定職業です. 工業や研究に特化しており、武器の使用は制限されます.

> [!NOTE]
> 科学技術を選んだプレイヤーは科学使い固定となり、剣、弓、ボウガン、槍などの武器は使用できません. 斧、クワ、ピッケル、シャベルなどの道具は使用できます. また、魔法技術陣営は科学使いには就職できず、弓とボウガンは弓使いのみ使用可能です. それ以外の武器は魔術陣営なら全職業で使用できます. 魔法はオーバーワールドでも使用可能です. 強き者は弱き者の味方をしましょう.

> [!WARNING]
> 職業のリセットにはお金がかかります. 慎重に選びましょう!

### 4.2 各職業の詳細

#### 4.2.1. Warrior - 戦士
* 最前線で敵のヘイトを集めつつ、強力な近接攻撃で敵陣を粉砕する物理アタッカーです.
* パッシブエフェクト:
  * 剣や斧などを装備した時の近接ダメージ: +20%
  * ノックバック耐性: +15%.
* 固有スキル:
  * ウォークライ: 周囲の敵を威嚇し、一定時間自身と味方の攻撃力を上昇させる.
  * クリーブラッシュ: 前方扇状の敵全体に大ダメージを与え、防御力を一時的に低下させる.
  * リアリスフレーゼ: クラスに縛られない [特殊スキル](#428-warrior-専用追加スキル) を取得できる. 
* 制約と弱点:
  * 基礎機動力が低いため飛行型モブや遠距離の敵に苦戦します.

#### 4.2.2. Assassin - 暗殺者
* 驚異的な俊敏性と高いクリティカル率で単一ターゲットを瞬時に仕留めるスピードスターです.
* パッシブエフェクト:
  * 常時移動速度 +30%
  * 背後からの攻撃時ダメージ x2.5
* 固有スキル:
  * シャドウステップ: ターゲットの背後へ一瞬でテレポートし、次の攻撃を確定クリティカルにする.
  * スモークスクリーン: 煙幕を展開して敵のターゲットを解除し、一時的に完全ステルス状態となる.
* 制約と弱点:
  * 基礎近接攻撃力および最大体力が低く、乱戦や正面からの殴り合いには向きません.

#### 4.2.3. Guardian - 守護者
* 重厚な防具と強固な盾で味方への攻撃を一身に引き受けるメインタンクです.
* パッシブエフェクト:
  * 受けるダメージ -25%
  * 常時ノックバック完全無効
  * 盾構え時の移動ペナルティなし
* 固有スキル:
  * タウント: 周囲のモブの攻撃ターゲットを自身へ強制集中させる.
  * フォートレス: 数秒間、受けるあらゆるダメージを極限までカットし、味方へのダメージを肩代わりする.
* 制約と弱点:
  * 攻撃力と移動速度が極めて低く、ソロでの敵討伐には時間がかかります.

#### 4.2.4. Healer - 癒す者
* 味方の体力回復、バフ付与、状態異常解除を担うパーティの生命線です.
* パッシブエフェクト:
* 周囲の味方の自然回復速度向上、自身が受ける回復効果 +30%.
* 固有スキル:
  * サンクチュアリ: 地面に聖なる領域を展開し、範囲内の味方を継続回復しつつアンデッドモブに持続ダメージを与える.
  * リザレクション: 倒れた仲間をその場で復帰させる.
* 制約と弱点:
  * 攻撃手段がほぼ皆無であり、常に護衛役の仲間と共に行動する必要があります.

#### 4.2.5. Mage - 魔道士
* 呪文書を用いた詠唱パズルを解くことで、規格外の広範囲、高威力属性魔法を放つスペルキャスターです.
- パッシブエフェクト:
  * 属性耐性 +20%
  * 最大 MP 保有量増加
- 固有スキル:
  - メテオストライク: 指定地点に巨大な隕石を落とし、地形効果（延焼、爆発）と超広範囲大ダメージを与える.
  - フロストノヴァ: 周囲の敵を氷漬けにして移動、攻撃を封じる.
- 制約と弱点:
  * 防具適性が低く紙装甲.
  * 詠唱中は無防備になるため、パズルを解く速度と安全な位置取りが求められます.

#### 4.2.6. Archer - 弓使い
* 唯一、弓やクロスボウの装備と射撃が許可された遠距離専門職です.
* パッシブエフェクト:
  * 射程距離に応じたダメージ増加
  * 矢の消費確率 -50%
- 固有スキル:
  - レインオブアローズ: 指定エリアの上空から無数の矢の雨を降らせ、範囲内の敵を足止めする.
  - ピアシングショット: 障害物や複数の敵を貫通し、直撃したボスの装甲を無視する強力な一撃を放つ.
- 制約と弱点:
  * 至近距離での戦闘能力が極めて低く、矢の連射には精密なチャージ管理が必要です.

#### 4.2.7. Scientist - 科学使い / 科学技術陣営専用の特殊職業
* エンジン、パイプ、マシンによる自動化を担う工業技術者です.
* 武器制限:
  * 剣、弓、ボウガン、槍は使用できません.
  * 斧、ピッケル、クワ、シャベルなどのツール類は使用可能です.
- 固有スキル:
  * なし. 戦闘は苦手なため、異世界の探索は魔法技術の仲間と協力しましょう.

#### 4.2.8. Warrior 専用追加スキル

戦士のレベルアップや討伐実績で得られるスキルポイントを割り振ることで、攻撃性能や前線維持能力を特化させることができます.

#### 1. 攻撃強化系
- ヘビースラッシュ (Lv.1〜5)
  - 通常攻撃時に一定確率で範囲薙ぎ払いが発生し、周囲の敵にも 30%〜60% の拡散ダメージを与える.
- アーマーブレイカー (Lv.1〜3)
  - 防具を装備したモブやボスへのダメージが 15%〜35% 増加し、対象の防御力を数秒間低下させる.
- エクスキューション (Lv.1〜3)
  - 残り体力が 30% 以下の敵に対する近接クリティカルダメージが 50%〜100% 増加する.

#### 2. 生存や維持系
- ブラッドラスト (Lv.1〜3)
  - 近接攻撃で敵を撃破した際、自身の体力をハート 0.5〜1.5 個分回復し、3秒間移動速度が上昇する.
- アンチェインド (Lv.1〜2)
  - スローやスタンなどの移動阻害系デバフの効果時間を 25%〜50% 短縮する.
- バトルハードン (Lv.1〜5)
  - 連続で近接攻撃を受けるたび、被ダメージを段階的に最大 20% まで軽減する（3秒間ダメージを受けないとリセット）.

#### 3. 特殊アクション系
- リープアサルト (アクティブ / CT: 15秒)
  - 前方へ力強く跳躍し、着地時に衝撃波を発生させて周囲の敵を吹き飛ばしつつ短時間の鈍足を付与する.
- バーサークモード (アルティメット / CT: 90秒)
  - 15秒間、受けるダメージが 20% 増加する代わりに、攻撃速度 +40%、近接ダメージ +50%、全ノックバック無効状態となる.

## 5. 生活ユーティリティ

作業のストレスを減らし、工業や農業に集中できる便利機能を搭載しています. 

* CutAll Utility: 斧で原木を壊すと、繋がっている原木と葉を一括で伐採. 
* MineAll Utility: ピッケルで鉱石を壊すと、鉱脈を一括で採掘.
* DigAll Utility: シャベルで土、砂、砂利を一括掘削.

> [!WARNING]
> これらのシステムはオーバーワールドのみで有効です.

## 7. 災害と救済

オーバーワールドではごくまれに "災害" が発生します. これに対抗できるのは、武力を持った人たちです. 協力して切り抜けましょう!

## 8. 魔道士用の詠唱システム

魔道士が魔術を実行するためには "詠唱" が必要です. 呪文書を使用すると、目の前のタスクをこなす必要があります. 簡単なパズルです、誰でもできるでしょう?
