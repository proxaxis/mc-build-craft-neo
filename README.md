# Build Craft Neo for Minecraft Fabric Servers

ようこそ！ この MOD パックは、BuildCraft や IC2 などの往年の名作工業要素、Better Combat や RPG Series による本格アクション戦闘、銃火器や兵器による熾烈な戦争、そしてディメンション攻略と経済システムを統合した大規模複合 MOD パックです.

## 1. はじめに
 
ワールド参加時、プレイヤーは "科学技術陣営" か "魔法技術陣営" のいずれかを選択します. 両陣営は排他的であり、対向陣営の専用アイテムを扱うことはできません. 不足する資源や成果物はプレイヤー間取引で補い合いましょう！

### 1.1. 科学技術陣営
  - 剣、弓、クロスボウ、槍、トライデントなどのファンタジー武器は装備不可. 
  - オノ、ピッケル、シャベル、クワなどの工業用ツール、および一部の近代火器のみ使用可能. 
  - 初期職業は "科学使い" に固定されます. 

### 1.2. 魔法技術陣営:
  - 弓とクロスボウを除く近接武器や魔法具を幅広く使用可能. 
  - 遠距離武器を扱えるのは職業 "弓使い" のみです. 
  - 職業 "科学使い" は選択できず、高度な工業機械の直接操作は制限されます. 

## 2. 基本概念

### 2.1. リソース

#### 2.1.1. `MJ` - `Minecraft Joules`
- 工業の基本動力単位
- BC や IC2 における `RF` や `EU` の換算規格です. 
- エンジンや発電機からキネシスパイプや電線を経由してマシンに供給されます. 
- クァーリー、粉砕機、ポンプなどの稼働に必須です. 

#### 2.1.2. `MD` - `Minecraft Dollar`
- 経済単位です. 
- 専用コインや ATM、自動販売機、オークションネットワークを介して流通します. 
- プレイヤー間取引、物資売買、土地の開放と維持、職業リセットなどに利用されます. 

#### 2.1.3. `MP` - `Magic Point`
- 魔法技術陣営の魔法行使に必要な魔力リソースです. 
- スペルブックの装備、詠唱、各種魔術の発動時に消費されます. 

#### 2.1.4. `EFP` - `Environmental Foot Print`
- 重工業機械の連続稼働や近代兵器の乱用によって蓄積する環境汚染・環境負荷指数です. 
- 指数が上昇すると課税が発生するほか、オーバーワールドに壊滅的な "災害" を引き起こします. 


## 3. 世界

### 3.1. オーバーワールド - Over World

生活、工業、開拓の拠点となる通常世界です. 普段は穏やかですが、環境負荷指数が高まると軍事ゲリラやモンスターの大軍が襲来する "災害" が発生します. 

### 3.2. 攻略ディメンションおよびダンジョン

強力なボスや古代遺物が眠る高難度エリアです. 魔法陣営の武力や、科学陣営の銃火器による遠征が不可欠です. 

- 黄昏の森 - The Twilight Forest:
  - 鬱蒼とした薄暮の森が広がる進行型ディメンション. ナーガ、リッチ、ヒドラ、雪の女王など段階的なボス攻略が求められます. 
- 天空の世界 - The Aether:
  - 雲の上に広がる神聖な浮島ディメンション. 青銅・銀・金の3大ダンジョンと固有のレリック武具が存在します. 
- 厄災 - L_Ender's Cataclysm:
  - オーバーワールド、ネザー、エンド深層に生成される超高難度巨大構造物. Netherite Monstrosity や Leviathan などの凶悪なエンドゲーム級ボスが待ち受けます. 


## 4. 科学技術

科学技術陣営のプレイヤーは、自動化設備と近代兵器を駆使して資源を掌握し、インフラを構築します. 

- エンジン: 燃料などを消費して、自動で MJ を生み出す装置. RS 信号だけで動くものから、核エネルギーまで様々.
- パイプ: アイテムを運ぶ装置. ネットワークを構築して倉庫システムを構築することも可能です.
- 掘削機: 露天掘り機. 地上から岩盤まで全自動で採掘します. 
- 回路制御: 壁面配線可能な RS ワイヤーと小型論理回路素子により、マシンの精密なオンデマンド制御を実現します.
- 近代火器: 高精度な 3D アニメーションを持つハンドガン、アサルトライフル、スナイパーライフルを製造できます. 魔法を使えない科学陣営にとって貴重な、敵対モブに対抗する主力兵装です. 
- 兵器: 車両や定置重機関銃などの防衛兵器を配備し、拠点を強固に要塞化します. 

> [!NOTE]
> 科学技術陣営のプレイヤーは、職業 "科学使い" に固定です. その他の職業には就けません.

## 5. 魔法技術

多種多様な職業、武器、魔術体系と滑らかなコンボや武器固有モーションで迫力のある戦闘が楽しめます.

| 職業 | 主な役割 | 武器系統 | 特徴 |
| :--- | :--- | :--- | :--- |
| 戦士 - Warrior | 近接攻撃 | 大剣、両手斧、刀 | 高い物理火力、範囲薙ぎ払い、ノックバック耐性 |
| 暗殺者 - Assassin | 機動力 | サイ、クナイ、短剣 | 壁蹴り、二段ジャンプ、高速移動、背後致命傷 |
| 守護者 - Guardian | タンク | 大型盾、パリィ、片手剣、メイス | スタン、被ダメージ軽減、ヘイト固定 |
| 魔道士 - Mage | 範囲攻撃 | 魔法書 | 魔法書による属性魔法、詠唱パズル |
| 聖職者 - Healer | 治癒 | 魔法書 | 聖なる祈祷、範囲継続ヒール、蘇生、アンデッド浄化 |
| 弓使い - Archer | 遠距離 | 弓、クロスボウ、魔法書 | 弓とクロスボウの専用クラス、特殊矢、トラップ展開 |
| 科学使い - Scientist | 工業 | 銃火器 | 工業専門、銃火器以外の武装不可 |

> [!NOTE]
> 魔法技術陣営のプレイヤーは "科学使い" は選択できません.

## 6. 経済

- 通貨流通:
  - 銅、鉄、金、エメラルド、ダイヤモンド、ネザライト規格の硬貨が流通. 
  - クエスト達成、ダンジョンボスの討伐、工業中間素材の納品によって獲得できます. 
- マーケットと物流:
  - 科学陣営が生産した機械部品や精製燃料と、魔法陣営が持ち帰った異世界のドロップ素材を取引所で売買可能. 
  - プレイヤー独自のショップ端末やネットワーク自販機を設置できます. 
- 土地保護と維持費:
  - クァーリー等で環境を削る科学拠点は、定期的に維持管理費を納める必要があります. 


## 7. 災害

環境負荷指数（EFP）が一定値を超えると、オーバーワールドの平穏は破られ "災害イベント" がトリガーされます. 

- 武装ゲリラ部隊や銃火器を装備したモブが拠点へ一斉進軍を開始します. 
- 科学陣営の防衛力と、魔法陣営の広範囲殲滅や防護結界を組み合わせて拠点を死守してください. 
- 撃退に成功すると、希少なハイテク資材や高額の報酬、特殊エンチャント結晶が授与されます. 

## 8. 生活ユーティリティ

作業のルーチンワークを減らし、建築や冒険に集中するためのアシスト機能を標準搭載. 

- 原木ブロックの破壊で樹木全体を一括伐採. 
- 同種鉱脈を一括で採掘. 
- 土、砂、砂利を一括掘削. 

> [!NOTE]
> オーバーワールド限定機能です.
